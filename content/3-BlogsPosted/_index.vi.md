### [Blog 1 - GIỚI THIỆU AWS CONTINUUM: DỊCH VỤ AI AGENT SĂN LỖ HỔNG VÀ MỞ PULL REQUEST VÁ CODE TỰ ĐỘNG](3.1-Blog1/)

- **Nguồn bài viết gốc:** [AWS News Blog (22/10/2026)](https://aws.amazon.com/blogs/aws/aws-continuum-for-code-vulnerabilities-is-now-generally-available/)
- **Tác giả:** Esra Kayabali (Principal Solutions Architect tại AWS)
- **Minh chứng bài đăng cộng đồng:** [Xem bài viết trên nhóm Facebook AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj/posts/2319591015472524/)
- **Tóm tắt nội dung:** Bài viết giới thiệu dịch vụ bảo mật tự chủ **AWS Continuum for code vulnerabilities** vừa chính thức phát hành rộng rãi (GA) ngày 22/10/2026. Đây là bước đột phá mang tính thời đại trong lĩnh vực DevSecOps, kết hợp Đồ thị Ngữ cảnh (Context Graph) giữa mã nguồn và cấu hình hạ tầng AWS thực tế để loại bỏ báo động giả, tự động chạy kịch bản thử nghiệm tấn công (Proof-of-Concept) trong Sandbox biệt lập để chứng minh tính khả thi của lỗ hổng, và tự động dùng Frontier AI viết code mở **Pull Request (PR)** vá lỗi trên GitHub/GitLab. Đảm bảo an toàn tuyệt đối với cơ chế phê duyệt tối thượng thuộc về con người (Human-in-the-loop).
